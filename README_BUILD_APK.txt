طريقة استخراج ملف APK من هذا المشروع:
1. فك الضغط عن الملف Haflati-Android-Project.zip
2. افتح المجلد HaflatiAndroid عبر برنامج Android Studio
3. أضف خطوط Cairo (cairo_regular.ttf, cairo_medium.ttf, cairo_semibold.ttf, cairo_bold.ttf) داخل:
   app/src/main/res/font/
4. انتظر اكتمال مزامنة Gradle ثم اختر من القائمة العلوية:
   Build > Build Bundle(s) / APK(s) > Build APK(s)
5. ستجد ملف app-debug.apk جاهزاً للتثبيت على أي هاتف أندرويد.
